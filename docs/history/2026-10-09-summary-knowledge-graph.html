Reading it as an engineer

Model and metamodel

The second figure is the profile: which Types exist and which links are legal between them. The first is a model instance that obeys it. The database enforces the profile, as a DOORS link module would.

Views are viewpoints

Plan, Recipes and Gym hold no data. Each is a query over the one model, the way a SysML diagram is a view and not a copy. That is why a new Schedulable Type appears on Plan with no extra work.

Built for AI across everything

Because every Item, link and date sits in one typed graph, an AI can answer across Modules: plan dinners around gym days and Saturday’s shop, or suggest an outfit for Dishoom. It reads under the same visibility rules as the person asking.
