# Module specs

One file per Module, written at the start of its stage — not before.

| Module | Types | Stage |
|---|---|---|
| `lists` | List, Shop | 4b |
| `food` | Recipe, Variation, Meal, Ingredient | 4 |
| `fitness` | Exercise, Workout template, Workout (5); Cardio activity (8) | 5, 8 |
| `goals` | Goal | 5 |
| `wardrobe` | Garment, Outfit, Outfit worn | 6 |
| `health` | — (daily metrics, a time series) | Later |
| `finance` | Account | 9 |

The core's own Types (Thought, Note, Task, Event) are specified with Stage 2 and
Stage 3. The [data model](../../20-architecture/data-model.md) and the
[capability map](../capability-map.md) hold what is decided so far; open
points for particular specs are listed in the [roadmap](../../roadmap.md#open-questions).
