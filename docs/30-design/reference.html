LifeOS · Design system · agreed 9 October 2026

The LifeOS look

Stone on true neutral greys, with one colour per Module, soft shadows and a faint hairline edge on cards, rows and the drawer. Built entirely from shadcn/ui. This page is the visual reference; the written rules and exact values are in the repository, under docs/30-design/, and they win if the two ever differ.

Mode

Module colours

One colour per Module, tuned separately for light and dark so each reads clearly on its own background. Thought, Note, Task and Event belong to the core, so they're shown in grey and told apart by their icons.

How it's done in shadcn

The standard theme variables, with a neutral palette. Each Module adds one colour variable. A Module's pages set shadcn's --primary and --ring to that colour, so every component on them follows without any change to the components.

Where colour is never used

Not for decoration, and not to mean "good" or "bad". Overdue and delete stay red, saved stays green, whichever Module you're in.

On a Module's own pages

Its colour takes over shadcn's primary and ring: the main button, selected tab, checkboxes, progress and focus. The drawer tints the current page in it. Everywhere else the primary is ink.
