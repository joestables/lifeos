# ADR-0024: Goals

**Status:** Provisionally agreed · 2026-10-09

## Context

Goals are the joined-up payoff: progress measured from the rest of the app,
not entered by hand.

## Decision

- Four kinds: **target** (bench 60 kg), **total over a period** (50 km in
  October), **habit / frequency** (gym 3× a week, with streak), **milestone**
  (book the Japan trip — done when its linked Tasks are done, or ticked).
- Measured by **rules picked from a list each Module publishes**, not a free
  formula builder.
- **Manual links allowed** on any goal; only milestone goals count them
  towards progress.
- **One level of sub-goals** (Get fit → Bench 60 kg, Run 50 km/month).
- Personal by default; Household goals possible, with the visibility rules of
  [ADR-0016](0016-sharing-and-visibility.md).

## Consequences

How "on track" is judged: [ADR-0025](0025-goal-on-track-by-kind.md)
